# Cisco Packet Tracer Projects

Open the projects in `final/` for submission. The `legacy/` directory is an archive of earlier and duplicate saves.

## Opening a project

1. Launch Cisco Packet Tracer.
2. Choose **File → Open**.
3. Select the required `.pkt` file.
4. Use **Realtime** mode for normal operation or **Simulation** mode to inspect packet flow.

## Verification examples

- Experiment 6: ping between PCs inside each topology section.
- Experiment 10: `show ip route` and end-to-end PC pings.
- Experiment 11: `show ip dhcp binding`, `show ip route`, and `ipconfig /renew`.
- Experiment 13: `show ip route rip`, `show ip ospf neighbor`, or `show ip eigrp neighbors`.
- Experiment 16: HTTP browser, FTP login, `nslookup`, DHCP lease, Telnet, SSH, and email tests.
